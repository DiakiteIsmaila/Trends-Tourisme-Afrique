\# Trends — Tourisme international en Afrique



Projet d’analyse de données réalisé dans le cadre du projet \*\*Trends\*\* de Gaea21.



\## Objectif



Analyser l’évolution et les tendances du tourisme international dans plusieurs destinations africaines à travers trois dimensions principales :



\- les arrivées touristiques internationales ;

\- les recettes du tourisme international ;

\- la provenance des touristes.



\## Pays étudiés



\- Maroc

\- Tunisie

\- Égypte

\- Afrique du Sud

\- Kenya

\- Tanzanie

\- Maurice



\## Données



Les données proviennent notamment de sources institutionnelles et statistiques telles que :



\- World Bank — World Development Indicators (WDI)

\- organismes nationaux du tourisme ;

\- instituts nationaux de statistiques ;

\- ministères et administrations compétentes.



Les données sont auditées et harmonisées avant leur utilisation.



\## Structure du projet



\- `data/raw/` : données sources

\- `data/processed/` : données intermédiaires et harmonisées

\- `data/final/` : datasets finaux

\- `notebooks/` : analyses exploratoires

\- `src/` : scripts Python de traitement et d'analyse

\- `dashboard/` : application Streamlit

\- `reports/figures/` : visualisations exportées

\- `reports/exports/` : résultats exportés

\- `docs/` : documentation méthodologique



\## Méthodologie



L'analyse respecte plusieurs principes :



\- aucune donnée manquante n'est assimilée à zéro ;

\- aucune interpolation ou extrapolation non justifiée ;

\- conservation des sources et de la traçabilité ;

\- distinction entre comptages exacts, parts, agrégats et données de couverture partielle ;

\- prise en compte du périmètre de couverture avant toute comparaison entre pays.
